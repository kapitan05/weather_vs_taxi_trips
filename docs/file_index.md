# File Index

## Root

| File | Purpose |
|------|---------|
| `main.py` | ETL entry point — creates Spark session, calls `ingest_tlc_data` + `ingest_weather_data` then `run_pipeline` for a given year/month range |
| `pyproject.toml` | Project metadata, runtime deps (fastapi, pyspark, psycopg2-binary, …), dev deps (pytest, locust, httpx), pytest config |
| `uv.lock` | Locked dependency tree generated by `uv` — do not edit manually |
| `.env.example` | Template for prod credentials; copy to `.env` before running `docker-compose.prod.yml` |
| `CLAUDE.md` | Instructions for Claude Code — project overview, architecture, commands, constraints |
| `README.md` | Project overview, quick-start commands, service URLs, project layout |

## docker/

| File | Purpose |
|------|---------|
| `Dockerfile.api` | Builds the FastAPI container — `python:3.13-slim` base, installs deps via `uv`, copies `src/`, starts uvicorn |
| `Dockerfile.etl` | Builds the PySpark ETL container — `jupyter/pyspark-notebook` base, installs deps via `uv`, copies `src/` and `main.py` |
| `nginx.conf` | nginx reverse-proxy config — proxies `/api/` to the FastAPI container, serves `src/frontend/` as static files at `/` |

## docker-compose files

| File | Environment | Key behaviour |
|------|-------------|---------------|
| `docker-compose.yml` | dev | Hot-reload API, Jupyter/PySpark on :8888, hardcoded dev credentials |
| `docker-compose.test.yml` | test | Ephemeral DB, `test-runner` service runs pytest then exits; `--abort-on-container-exit` causes the whole stack to stop on completion |
| `docker-compose.prod.yml` | prod | nginx on :80, credentials from `.env`, `restart: always`, no Jupyter |

## src/db/

| File | Purpose |
|------|---------|
| `schema.sql` | Idempotent DDL — creates `staging` and `analytics` schemas, all 5 tables, and date-column indexes. Run once by the `db-init` Docker service |

---

## src/ingest/

| File | Purpose |
|------|---------|
| `logging_config.py` | `JsonFormatter` class + `setup_json_logging()` — configures the root logger to emit structured JSON lines |
| `taxi_ingest.py` | `ingest_tlc_data(spark, year, month)` — downloads the NYC TLC yellow-taxi Parquet file for a given month, filters invalid rows (zero fare / distance / passengers), writes to `staging.fact_trip` via JDBC |
| `weather_ingest.py` | `ingest_weather_data(spark, year, month)` — fetches hourly weather from Open-Meteo API with retry/backoff, validates response schema, converts to Spark DataFrame, writes to `staging.fact_weather` via JDBC |

---

## src/transform/

| File | Purpose |
|------|---------|
| `pipeline.py` | `run_pipeline(spark)` — reads `staging.fact_trip` and `staging.fact_weather`, aggregates to daily granularity, computes dominant weather code via window function, joins on date, writes `analytics.daily_trips`, `analytics.daily_weather`, `analytics.daily_correlation` |

---

## src/api/

| File | Purpose |
|------|---------|
| `main.py` | FastAPI application — registers lifespan (pool init/close), CORS middleware, all three routers, global 500 exception handler, `GET /api/health`, `GET /` (serves frontend), `StaticFiles` mount |
| `db.py` | psycopg2 `ThreadedConnectionPool` (2–10 conns) — `init_pool()`, `close_pool()`, `get_conn()` context manager; connection params from env vars with dev defaults |
| `models.py` | Pydantic response models: `DailyTrips`, `DailyWeather`, `DailyCorrelation` — shapes returned by the API and validated against DB rows |

### src/api/routers/

| File | Purpose |
|------|---------|
| `trips.py` | `GET /api/trips/daily?start=&end=` — queries `analytics.daily_trips` with optional date range filter, returns `list[DailyTrips]` |
| `weather.py` | `GET /api/weather/daily?start=&end=` — queries `analytics.daily_weather` with optional date range filter, returns `list[DailyWeather]` |
| `correlation.py` | `GET /api/correlation/?start=&end=` — queries `analytics.daily_correlation` with optional date range filter, returns `list[DailyCorrelation]` |

---

## src/frontend/

| File | Purpose |
